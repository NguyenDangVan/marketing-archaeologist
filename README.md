# Marketing Archaeologist

Công cụ mã nguồn mở reverse engineer cách các thương hiệu làm marketing trong một ngách, dựa trên bằng chứng công khai (quảng cáo, fanpage, TikTok, YouTube, sàn TMĐT, website), và biến phát hiện thành playbook có dẫn chứng, cập nhật khi thị trường thay đổi.

Thị trường đầu tiên: Việt Nam.
